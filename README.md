## ⚙ Installation

### Clone Repository

git clone https://github.com/yourusername/portfolio-pro.git

### Move Into Project

cd portfolio-pro/frontend

### Install Dependencies

npm install

### Run Development Server

npm run dev

### Build Project

npm run build

### Preview Build

npm run preview
